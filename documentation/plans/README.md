Approved target architecture and module specifications. [`architecture/`](../architecture/)
describes what runs today; this folder describes what we have agreed to build.

Every module plan starts from [`MODULE_PLAN_TEMPLATE.md`](MODULE_PLAN_TEMPLATE.md) and links to
the research teardown(s) it came from.

Status is **not** repeated here (it went stale when it was): see the status overview in [`checklist.md`](checklist.md).
