**Method.** Read and searched `apps/web/src` (40 `.tsx` files, `styles.css`, `theme.css`), ran `typecheck`, `npm test` and a Vite production build. **No browser was used** (`agents.md`), so anything that needs eyes (contrast, real RTL rendering, overflow at a given window width, dark mode) is listed as *not checked*, not as passing.

## Checked and clean
- No physical CSS (`margin-left`, `ml-`, `text-left`, `float`, `left:`/`right:`): layout is RTL-ready in code.
- No hard-coded colours in `.tsx`; theme tokens are used.
- Visible focus ring (`:focus-visible`), reduced-motion respected, `<main>` and labelled `<nav>` landmarks, inputs are wrapped in `<label>`.
- No `onClick` on non-interactive elements; no swallowed errors; `useLoad` shows loading and error states.
- Tables sit inside a horizontally scrolling wrapper (`.table-wrap`).
